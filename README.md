# Computational supplements for cyclic Hamming covering codes

This repository contains the computational supplementary materials for the
manuscript

> The Cost of Cyclic Adjacency for Hamming Covering Codes

submitted to the *Journal of Combinatorial Optimization*.

The five ZIP archives are distributed as the release assets for the dated
release `2026-10-04`:

1. manifest and reproducibility tools;
2. five final orbit exclusions;
3. earlier checked binary exclusion branches;
4. duplicate-window linear reductions;
5. finite feasibility and construction checks.

Each archive contains its own `README_JCO.md`, file manifest, and verification
scope. The archives preserve the computational records used in the manuscript;
exploratory connected-length-64 runs are labelled unresolved and are not used
as lower-bound evidence.

The release assets are large compressed archives. Users should download the
assets rather than clone them into the Git history. The SHA-256 values and
resource descriptions are recorded in the release notes and in the manifests
inside the archives.
